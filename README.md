# Smart To-Do List

## Project Overview
A Python desktop application designed to organize tasks, track priorities and manage deadlines.

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Undo completion
- High, Medium and Low priorities
- Deadline entry
- Automatic JSON storage
- Task statistics
- Clear completed tasks

## Technologies
- Python
- Tkinter
- JSON

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run `py todo_app.py`.

## Learning Outcomes
- GUI development
- Python functions
- Lists and dictionaries
- JSON file handling
- Exception handling
